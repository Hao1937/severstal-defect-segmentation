## 分工与位置

| 位置 | 职责 |
| --- | --- |
| Mac：`/Users/wangyuhao/Resource/courses/BigData` | 编辑代码、配置和文档；提交主线 `main` |
| Legion：`/home/wyhao/git/BigData.git` | Git 裸仓库，接收提交；Mac 远端名为 `legion` |
| Legion：`/home/wyhao/projects/BigData` | 训练工作副本，从裸仓库拉取；运行训练和推理 |
| Legion 工作副本的 `data/`、`weights/`、`runs/` | 数据、下载权重、实验产物；不进 Git |

代码通过 Git 同步，环境分别安装。先使用已有 SSH 连接建立私有远端；后续需要异地备份或多人协作时可再加 GitHub 私有远端。

## 日常流程

1. 在 Mac 修改代码与配置，同步设计、决策或实验文档。
2. 完成相关检查和 neat-freak 收尾后提交，推送到 Legion 裸仓库。
3. Legion 没有正在运行的本项目任务时，拉取新提交并开始实验。
4. 每次运行保存代码 commit、实际配置、初始化来源和结果，放入独立运行目录。
5. 将小型指标和选定图像回传 Mac，在实验记录中解释结果；大权重和完整预测留在 Legion。

Mac 提交后同步：

```sh
git push legion main
ssh legion 'git -C /home/wyhao/projects/BigData pull --ff-only'
```

训练期间不更新训练工作副本；Mac 可以继续编辑、提交和推送，待本轮结束再拉取。需要并行跑不同版本时再增加工作副本。

## 文件与版本

- Git 保存源码、配置、依赖说明、数据获取与划分方法、文档和精选结果。
- 数据集、权重、环境、完整预测和运行日志由 `.gitignore` 排除。
- 小改动直接提交 `main`；探索较大改动使用短分支，检查后合回。
- 默认在 Mac 改源码。若在 Legion 紧急修改，先提交到独立分支，再由 Mac 拉取合并；不通过整目录覆盖回传。
- 回传使用指定文件或目录，不使用带删除选项的双向镜像。实验目录包含 E 编号与运行编号。

裸仓库与工作副本的分工参考 [Git 官方说明](https://git-scm.com/book/en/v2/Git-on-the-Server-Setting-Up-the-Server)。
