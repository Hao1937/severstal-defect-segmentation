## 首轮实现细节与理由

以下对应 `configs/unet_resnet34.yaml` 和 `severstal/`，记录首次实现；改变设置时关联新的 D/E 编号。

| 细节 | 实现与理由 |
| --- | --- |
| 标签恢复 | RLE 从 1 计数，按列展开，恢复为高 256、宽 1600 的四通道掩膜；CSV 缺失的图像—类别行补空掩膜，保留正常图。 |
| 划分 | 固定 seed 42，多标签分层同时考虑四类阳性和正常图。训练 10,054、验证 2,514；逐类阳性为 718/198/4120/641 与 179/49/1030/160。保留共享文件，所有成员用同一划分。 |
| 初始化 | 编码器用 ImageNet 权重，分割解码器新初始化。ResNet34 从 torchvision 官方权重入口加载；完整公开赛题权重仅用于 E01 展示。 |
| 输入 | RGB 像素除以 255，再使用 ImageNet mean 0.485/0.456/0.406、std 0.229/0.224/0.225，匹配预训练输入。 |
| 采样 | 每轮打乱训练原图，每图随机裁一块；先保留自然样本比例，依据稀有类漏检再决定是否重采样。 |
| 裁剪与标签 | 保留全部高度，横向均匀选择 512 像素窗口，图像和掩膜同步。分类标签由裁剪后的掩膜重算；分类器当前使用全图。 |
| 增强 | 水平和垂直翻转各 50%；像素乘随机 0.9—1.1 对比度系数，再加随机 −25.5—25.5 亮度，裁到 0—255。用基础增强增加外观变化，暂不引入 mixup 或复杂形变。 |
| 输出 | 四通道 logits，分别 sigmoid；允许同图含多类，不使用互斥 softmax。 |
| 优化 | AdamW，lr 3e-4、weight decay 1e-4，使用 PyTorch 原生实现以便维护；当前是统一起点，尚无优化器优劣的本项目对照。 |
| 显存 | 自动混合精度加 GradScaler；每个实际 batch 更新一次，没有梯度累积。ResNet34 分割 batch 4，完整图验证 batch 1，实际显存记录到 E02。 |
| 验证 | 完整 256×1600，不做增强或 TTA；像素阈值 0.5，首轮不做门控和面积过滤，保留模型原始误报与漏报。 |
| 指标 | 官方 Dice 逐图逐类平均；非空 Dice 只统计真实存在缺陷的图像—类别对。检出按该对预测是否非空计数，并非实例匹配召回；错误分析另列与标注有交集的阳性图数，见 D38。 |
| 选权重与停止 | 最佳分割权重按非空 Dice 选择；连续 3 次未改善时 ReduceLROnPlateau 降低学习率（patience=2），连续 7 轮未改善停止，上限 30 轮。分类器改用 macro-F1。 |
| 保存与续训 | 保存最佳权重，以及最近一轮的模型、优化器、学习率调度、混合精度和随机状态；续训沿用原配置与划分。固定种子，启用 cuDNN benchmark，不承诺逐位一致。 |

损失对每个图像—类别的像素计算：

\[
L=0.75\,\mathrm{BCEWithLogits}(z,y;w_c)+0.25\,\operatorname{mean}_{|y|>0}\left(1-\frac{2\sum p y+1}{\sum p+\sum y+1}\right),\quad p=\sigma(z).
\]

其中正像素权重为 2/2/1/1.5，负像素权重为 1。BCE 对所有像素取平均，Dice 项只平均非空图像—类别对；整个 batch 无缺陷时 Dice 项为 0，空图仍由 BCE 学习。按类加权 BCE 与 Dice 的方向借鉴 S01；具体比例、正例权重和逐样本非空 Dice 属于我们的初始实现选择，尚未做参数对照。

## 融合与实验问题

1. 自主训练模型先对齐概率图并等权平均，检查每个成员带来的新增正确检出和误报。[D19](决策记录.md#d19)、[E03](实验记录.md#e03)
2. 比较无门控、硬门控、概率相乘、动态面积阈值四种处理，观察分类漏检如何影响分割。[D08](决策记录.md#d08)、[E04](实验记录.md#e04)
3. 分别比较整类掩膜面积和连通区域面积过滤，按缺陷大小分析收益与损失。[D20](决策记录.md#d20)、[E05](实验记录.md#e05)

融合入口为 [evaluate_ensemble.py](../severstal/evaluate_ensemble.py)：A/B 阶段使用 [ensemble_ab.yaml](../configs/ensemble_ab.yaml)，比较原始与共同面积过滤；加入 C 后使用 [ensemble_abc.yaml](../configs/ensemble_abc.yaml)，补齐七种组合与六种门控。两阶段均已完成。模型使用各自按非空 Dice 选出的最佳权重，逐图计算 float32 等权概率平均，不做 TTA；保留全部逐图指标与固定案例 float32 概率，不额外生成全量概率缓存。[D46](决策记录.md#d46)

伪标签、按类专家、Lovasz 微调、分类骨干迁移与参数平均列为后续候选；依据误差分析选择。[D22—D25](决策记录.md#保留的扩展与待定项)
