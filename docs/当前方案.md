## 目标与评价

输入钢板图像，输出四类像素掩膜。课程交付为 demo、约 20 页以上 slides、Word 报告、源码和数据集，并说明来源、分工、问题分析和个人贡献。原文见[作业要求](../作业要求.md)，赛题规模与指标公式见[赛题调查](../Severstal调研/00_赛题与迁移结论.md)。

研究主线：**不同模型是否互补，分类信息怎样减少误报并保留小缺陷。** 同时报图像—类别平均 Dice、非空 Dice、逐类检出与误报/漏报案例。[D01—D02、D06—D07](决策记录.md#范围与评价)

## 训练起点

| 设置 | 当前建议 | 决策 |
| --- | --- | --- |
| 设备 | Legion；已确认 RTX 3070 Laptop 8GB、PyTorch 2.7.1+cu128，CUDA 可用 | [D32](决策记录.md#d32) |
| 执行 | 每次训练一个成员；推理也可分模型生成预测再融合 | [D14](决策记录.md#d14) |
| 初始化与划分 | ImageNet 编码器权重；原图多标签分层 80/20，seed 42，先划分再裁剪 | [D33](决策记录.md#d33) |
| 分割尺寸 | 256×512 裁剪训练，256×1600 全图验证 | [D16](决策记录.md#d16) |
| 显存设置 | 混合精度；ResNet34 分割 batch 4，其余成员 2，验证 batch 1 | [D34](决策记录.md#d34) |
| 分类输入 | 先用全图；若裁剪，按裁剪后掩膜重新计算类别标签 | [D18](决策记录.md#d18) |
| 时间预算 | 首轮最多 30 epochs，连续 7 轮未改善停止；按实测耗时安排后续成员 | [D34](决策记录.md#d34) |

初始损失为 0.75 加权 BCE + 0.25 非空 soft Dice；AdamW，学习率 3e-4。随机打乱图像，使用水平/垂直翻转及轻量亮度对比度增强。分割最佳权重按非空 Dice 选择。完整设置与变更理由见 [D33—D35](决策记录.md#d33)。

## 融合与实验问题

1. 自主训练模型先对齐概率图并等权平均，检查每个成员带来的新增正确检出和误报。[D19](决策记录.md#d19)、[E03](实验记录.md#e03)
2. 比较无门控、硬门控、概率相乘、动态面积阈值四种处理，观察分类漏检如何影响分割。[D08](决策记录.md#d08)、[E04](实验记录.md#e04)
3. 分别比较整类掩膜面积和连通区域面积过滤，按缺陷大小分析收益与损失。[D20](决策记录.md#d20)、[E05](实验记录.md#e05)

伪标签、按类专家、Lovasz 微调、分类骨干迁移与参数平均列为后续候选；依据误差分析选择。[D22—D25](决策记录.md#保留的扩展与待定项)
