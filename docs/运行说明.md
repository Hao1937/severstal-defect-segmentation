## 环境

运行目录：Legion `/home/wyhao/projects/BigData`。项目解释器：`.venv/bin/python`。

2026-10-23 实测：RTX 3070 Laptop 8GB、Python 3.12.14、PyTorch 2.7.1+cu128、torchvision 0.22.1+cu128，CUDA 可用。项目虚拟环境复用 `mono_depth` 的 PyTorch，新增依赖安装在本项目 `.venv`，不改原环境。核心依赖见 [requirements.txt](../requirements.txt)。

## 数据与划分

```sh
.venv/bin/python -m severstal.download all
.venv/bin/python -m severstal.prepare
```

数据使用 [Kaggle 公开镜像第 1 版](https://www.kaggle.com/datasets/krishar01/severstal-steel-defect-detection)，保留原 `train_images`、`test_images` 与 RLE 标注格式。已核对 12,568 张训练图、5,506 张测试图；当前 CSV 为 `ImageId,ClassId,EncodedPixels` 三列，共 7,095 条非空标注，正常图通过训练图目录补齐。

划分按原图进行多标签分层，80% 训练、20% 验证，seed 42；四类阳性与无缺陷图共同参与分层。共享文件为 `data/split_seed42.json`，每次训练复制进运行目录。

## 公开集成展示

原权重使用历史 TorchScript 格式，现代 PyTorch 直接加载会失败。先在独立 Python 3.7 环境安装 [官方 PyTorch 1.4 CPU 版](https://pytorch.org/get-started/previous-versions/)，转换后比较同一真实全图的输出：

```sh
.venv-legacy/bin/python -m pip install torch==1.4.0+cpu -f https://download.pytorch.org/whl/torch_stable.html
.venv/bin/python -m severstal.convert_public prepare --image data/severstal/test_images/0000f269f.jpg
.venv-legacy/bin/python -m severstal.convert_public export
.venv/bin/python -m severstal.convert_public verify
```

示例图须替换为本机实际测试图文件名。原文件保留在 `weights/lightforever/`，转换权重、参考输出与对比记录在 `weights/lightforever-converted/`。转换不改结构和参数；对比通过后运行：

```sh
.venv/bin/python -m severstal.public_demo --output runs/E01-r02 --limit 32
```

从原作者 [Lightforever 模型包](https://www.kaggle.com/datasets/lightforever/severstalmodels)读取三个 TorchScript U-Net。按原 Notebook 使用 logits 平均、sigmoid、水平翻转还原后的概率平均；像素阈值 0.5，面积阈值 600/600/1000/2000。推理 batch 为 1，保留 float32。输出概率、RLE、叠加图和摘要；测试图展示不计算有标签成绩。

## 自主训练

```sh
.venv/bin/python -m pytest -q
.venv/bin/python -m severstal.train --config configs/unet_resnet34.yaml --output runs/E02-r01
```

另外三个配置在 [configs](../configs)；每次只启动一个成员。各运行保存代码 commit、展开配置、划分、逐轮指标、最佳与最近权重。分割权重按非空 Dice 选择，同时报告整体 Dice 和逐类误报漏报；分类器按 macro-F1 选择。

中断后从最近一轮继续：

```sh
.venv/bin/python -m severstal.train --config configs/unet_resnet34.yaml --output runs/E02-r01 --resume
```

训练期间保持工作副本版本固定。后台运行日志放在 `runs/setup/`，实测状态统一见[实验记录](实验记录.md)。

FPN/B3 的官方 ImageNet 权重由 Mac 按 SMP 指定 revision 下载，转存项目 `weights/huggingface/` 后即可离线加载。Legion 直连失败时使用该缓存，不改变模型初始化：

```sh
HF_HOME="$PWD/weights/huggingface" HF_HUB_OFFLINE=1 .venv/bin/python -m severstal.train --config configs/fpn_seresnext50.yaml --output runs/E02-r03
HF_HOME="$PWD/weights/huggingface" HF_HUB_OFFLINE=1 .venv/bin/python -m severstal.train --config configs/unet_efficientnet_b3.yaml --output runs/E02-r04
```

B3 在 FPN 训练及 A/B/A+B 对照完成后启动。实际下载版本与失败记录见 D46、E02-smoke03。

## 自主成员融合

```sh
.venv/bin/python -m severstal.evaluate_ensemble --config configs/ensemble_ab.yaml --output runs/E03-r01
.venv/bin/python -m severstal.evaluate_ensemble --config configs/ensemble_abc.yaml --output runs/E03-r02
```

前者需要 A/B 最佳权重，后者需要 A/B/C 及分类器逐图概率；所有成员核对同一原图划分。先 sigmoid 再等权平均，再共同后处理。保存各组合逐图指标、相对 A 及各成员的变化、类别 2 阳性对照和固定案例概率；不保存额外全量概率缓存。`--limit` 只用于短运行检查，正式成绩不使用该参数。

## 类别 2 诊断

训练结束、Legion 拉取包含诊断脚本的新版本后，可运行：

```sh
.venv/bin/python -m severstal.analyze_class2 --run runs/E02-r01 --output runs/E06-r02
.venv/bin/python -m severstal.review_area --run runs/E02-r01 --output runs/E05-r02
```

前者复制当时最佳权重，用 CPU 检查裁剪暴露、全部类别 2 阳性图及固定阴性子集的概率；后者直接从全量逐图验证记录精确重算整类面积过滤，不需要模型前向。输出目录使用新的运行编号，保留旧结果。2026-10-23 首次诊断为避免更新训练副本，使用 `runs/setup/` 下保存的脚本副本，位置及实际快照见实验记录。

## 分类与门控比较

```sh
.venv/bin/python -m severstal.train --config configs/classifier_resnet34.yaml --output runs/E02-r02
.venv/bin/python -m severstal.evaluate_gates --config configs/gating.yaml --output runs/E04-r01
.venv/bin/python -m severstal.gate_cases --run runs/E04-r01
.venv/bin/python -m severstal.area_frontier --run runs/E04-r01
```

依次执行：分类训练结束后再运行评测，且固定两个训练目录的最佳权重。评测读取已保存的分类概率，核对划分和标签，分割只前向一次；输出六分支逐图指标、摘要、变化案例和概率缓存。缓存约 7.67 GiB，程序检查保留至少 2 GiB 空间；仅在 Legion 保留，不进 Git。首次结果见 E04-r01。
