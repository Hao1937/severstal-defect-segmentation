### D31 · 2026-10-23 · 采用：Git 管理双端协作

用户要求建立 Git 并明确 Mac、Legion 的维护方式。采用 Mac 编辑提交、Legion 裸仓库接收版本、训练副本拉取执行；数据、权重和环境留在运行端。每次实验关联 commit 与配置，训练期间保持副本版本固定。这样能追溯结果，也避免两台电脑互相覆盖源码。操作见[双端协作](双端协作.md)，关联 E01—E05。

`D编号 · 日期 · 状态｜问题与来源｜选择、理由与代价｜关联实验/产物｜替代关系（如有）`

普通决策一行写清；只有存在多轮取舍时才另开短段落。原始材料中的每项技巧是候选知识，只有进入我们的设计或被明确排除时才建立 D 记录。
